# xkeen-sub

CLI-утилита для управления подписками Xray в XKeen на роутерах Keenetic с Entware.

## Возможности

- Добавление, просмотр, редактирование и удаление подписок.
- Загрузка и разбор подписок в форматах Xray JSON, Base64 и URI-ссылок.
- Поддерживаемые протоколы URI: VLESS, VMess, Trojan, Shadowsocks и Hysteria2.
- Обновление конфигураций Xray с проверкой итоговой конфигурации, резервным копированием и автоматическим откатом при ошибке.
- Управление резервными копиями.
- Отдельное меню чёрного списка: выбор подписки, блокировка/разблокировка отдельных подключений и просмотр всех действующих блокировок.
- Просмотр текущего узла, ручное переключение через RoutingService API и автоматический возврат к выбору балансировщика.
- Автоматическое обновление всех подписок или выбранной подписки по расписанию (через cron Entware).
- Обновление, переустановка и удаление самой программы.

Проект находится в разработке. Перед использованием на рабочем роутере рекомендуется проверить работу на своей конфигурации.

## Установка

Требуются Entware, установленный XKeen, Xray и доступ к интернету. Перед загрузкой программы установщик проверяет пакетный менеджер Entware и наличие `curl`, `ca-bundle` и службы cron. Недостающие пакеты (`curl`, `ca-bundle`, `cron`) устанавливаются автоматически вместе с их зависимостями; используется штатный пакет Entware `cron` (Vixie cron), а при проверке службы поддерживаются демоны `cron` и `crond`. Остальные пакеты Entware не обновляются. Для установки пакетов необходима рабочая команда `wget`, которую использует `opkg`. Если Entware или сам пакетный менеджер не работают, установщик покажет причину и остановится, не заменяя текущую версию программы. Установщик определяет архитектуру Entware и загружает подходящую сборку. До замены программы он также проверяет конфигурацию Xray: при наличии пользовательских балансировщиков предложит заменить их на `xkeen-sub-balancer` и перенаправить существующие правила `balancerTag`; пользовательские правила `outboundTag` не меняются. Если настройки Observatory отличаются от шаблона проекта, установщик отдельно предложит их заменить. Отказ от замены оставляет соответствующие настройки без изменений. Перед сохранением принятых изменений создаются резервные копии, а полный набор конфигураций проверяется через `xray run -test`; при ошибке активные файлы не изменяются. Если роутер был выключен и пропустил время запуска более чем на час, пропущенный запуск будет пропущен; расписание сохранит исходную привязку.

После публикации релиза выполните на роутере по SSH:

```sh
opkg update
sh -c "$(curl -fsSL https://raw.githubusercontent.com/PaulMarkey1/xkeen-sub/main/install.sh)"
```

Поддерживаемые архитектуры: `aarch64`, `mipsel`, `mips`.

Последние версии и файлы для скачивания: [GitHub Releases](https://github.com/PaulMarkey1/xkeen-sub/releases).

## Команды

| Команда | Назначение |
|---|---|
| `xkeen-sub` | Показать справку |
| `xkeen-sub --version` | Показать версию |
| `xkeen-sub setup` | Открыть меню подписок |
| `xkeen-sub node` | Просмотреть текущий узел, сменить подключение и настроить автоматический возврат |
| `xkeen-sub setup add` | Добавить подписку |
| `xkeen-sub setup list` | Просмотреть подписки |
| `xkeen-sub setup edit` | Изменить имя или URL подписки |
| `xkeen-sub setup del` | Удалить подписку и пересобрать конфигурации |
| `xkeen-sub update` | Обновить все подписки |
| `xkeen-sub update subN` | Обновить одну подписку |
| `xkeen-sub auto-update` | Управлять расписаниями автообновления |
| `xkeen-sub backup` | Настройки и просмотр резервных копий |
| `xkeen-sub uxs` | Обновить программу |
| `xkeen-sub reinstall` | Выбрать и установить другую версию |
| `xkeen-sub uninstall` | Удалить программу |

Команда `xkeen-sub node` (также доступна в `xkeen-sub setup` → пункт 7) открывает меню текущего подключения. Можно повторно запросить активный тэг, выбрать подключение из любой подписки (заблокированные узлы не отображаются) или настроить длительность ручного выбора. Для переключения используется `xray api bo` — перезапуск Xray не требуется.

Длительность ручного выбора по умолчанию — 10 минут; доступны 30 минут, 1, 3, 6, 12 и 24 часа, а также режим «до ближайшей перезагрузки Xray или обновления подписок». Для временных вариантов действует самое раннее условие: истечение выбранного времени, обновление подписок или перезагрузка Xray. Возврат к автоматическому выбору выполняется через существующую минутную cron-задачу автообновления; она остаётся включённой на время ручного выбора даже при отсутствии расписаний обновления.

Чёрный список открывается отдельно: `xkeen-sub setup` → пункт 6 → выбрать подписку → выбрать подключение. Он больше не находится в меню редактирования подписки.

### Резервные копии

```sh
xkeen-sub backup limit N         # Дневной лимит точек (минимум 5)
xkeen-sub backup mode auto       # Хранить точки 3 календарных дня
xkeen-sub backup mode unlimited  # Бессрочное хранение; место контролирует пользователь
xkeen-sub backup user-backup     # Создать ручную точку полного снимка
xkeen-sub backup list            # Список резервных копий
xkeen-sub backup list ID         # Открыть резервную запись
xkeen-sub backup clear           # Удалить все точки после подтверждения
```

Каждая новая точка — полный проверенный снимок конфигураций Xray и xkeen-sub. В автоматическом режиме точки хранятся 3 календарных дня; в пределах этого срока сохраняется не менее 5 завершённых точек за день. Первая точка дня и user-backup защищены от автоматического и индивидуального удаления на этот срок; команда backup clear удаляет их после отдельного подтверждения. В бессрочном режиме автоматическая очистка отключена — пользователь самостоятельно отвечает за свободное место. Старые точки прежнего формата сохраняют совместимость со старым выборочным восстановлением.

## Данные

Файлы программы хранятся в `/opt/etc/xkeen-sub/`.

- `sub.json` — список подписок.
- `baseline/` — исходные данные подписок.
- `backup/` — резервные копии и журналы операций.
- `old-user-outbound.json` — архив пользовательских подключений.
- `auto-update.json` — расписания автоматического обновления.
- `blacklist.json` — чёрный список подключений, привязанный к ID подписки и исходному Tag.
- `node.json` — настройка длительности принудительного выбора подключения.
- `node-state.json` — временное состояние принудительного подключения; удаляется после возврата к автоматическому выбору.

Исполняемый файл: `/opt/sbin/xkeen-sub`.
