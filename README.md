# xkeen-sub

CLI-утилита для управления подписками Xray в XKeen на роутерах Keenetic с Entware.

## Возможности

- Добавление, просмотр, редактирование и удаление подписок.
- Загрузка и разбор подписок в форматах Xray JSON, Base64 и URI-ссылок.
- Поддерживаемые протоколы URI: VLESS, VMess, Trojan, Shadowsocks и Hysteria2.
- Обновление конфигураций Xray с проверкой итоговой конфигурации, резервным копированием и автоматическим откатом при ошибке.
- Управление резервными копиями.
- Обновление, переустановка и удаление самой программы.

Проект находится в разработке. Перед использованием на рабочем роутере рекомендуется проверить работу на своей конфигурации.

## Установка

Требуются Entware, установленный XKeen, Xray и доступ к интернету. Установщик определяет архитектуру Entware и загружает подходящую сборку.

После публикации релиза выполните на роутере по SSH:

```sh
opkg update
sh -c "$(curl -fsSL https://raw.githubusercontent.com/PaulMarkey1/xkeen-sub/main/install.sh)"
```

Поддерживаемые архитектуры: `aarch64`, `mipsel`, `mips`.

Последние версии и файлы для скачивания: [GitHub Releases](https://github.com/PaulMarkey1/xkeen-sub/releases).

## Команды

| Команда | Назначение |
|---|---|
| `xkeen-sub` | Показать справку |
| `xkeen-sub --version` | Показать версию |
| `xkeen-sub setup` | Открыть меню подписок |
| `xkeen-sub setup add` | Добавить подписку |
| `xkeen-sub setup list` | Просмотреть подписки |
| `xkeen-sub setup edit` | Изменить имя или URL подписки |
| `xkeen-sub setup del` | Удалить подписку и пересобрать конфигурации |
| `xkeen-sub update` | Обновить все подписки |
| `xkeen-sub update subN` | Обновить одну подписку |
| `xkeen-sub backup` | Настройки и просмотр резервных копий |
| `xkeen-sub uxs` | Обновить программу |
| `xkeen-sub reinstall` | Выбрать и установить другую версию |
| `xkeen-sub uninstall` | Удалить программу |

### Резервные копии

```sh
xkeen-sub backup days N          # Срок хранения в днях
xkeen-sub backup limit N         # Лимит записей за день
xkeen-sub backup mode auto       # Автоматическое удаление старых записей
xkeen-sub backup mode unlimited  # Хранить без ограничения срока
xkeen-sub backup list            # Список резервных копий
xkeen-sub backup list ID         # Открыть резервную запись
```

Резервное копирование обязательно. По умолчанию записи хранятся 3 календарных дня, дневной лимит — 10 записей.

## Данные

Файлы программы хранятся в `/opt/etc/xkeen-sub/`.

- `sub.json` — список подписок.
- `baseline/` — исходные данные подписок.
- `backup/` — резервные копии и журналы операций.
- `old-user-outbound.json` — архив пользовательских подключений.

Исполняемый файл: `/opt/sbin/xkeen-sub`.
